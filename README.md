# SyrvänKyylä: tykkipelin Mini App
Kopioi tämän hakemiston sisältö erillisen julkisen repositorion juureen. Älä julkaise koko host-repositoriota.
GitHub Settings → Pages → Deploy from a branch → main / root. Tiedostot ovat suoraan julkaistavia; npm-buildia ei tarvita.
Kopioi julkaistu HTTPS-osoite Windows-hostin Telegram-asetusten Mini App -kenttään. Tyhjä kenttä palauttaa perinteisen ohjaimen.
Oikea testi: liity peliin, aloita kierros, avaa botin reply keyboardin laukauspainike Telegramissa, vahvista ja tarkista botin kuittaus sekä TV:n valmiusmerkintä. Testaa myös vanhan kierroksen hylkäys ja /tykki_perinteinen.
Ohjain ei sisällä tokenia tai henkilötietoja. Host välittää kierroksen julkiset tiedot fragmentissa, tarkistaa lähettäjän ja kuluttaa kertakäyttöisen istunnon transaktiossa.
Sivu tarvitsee Telegramin ja internetyhteyden. Se ei vastaanota reaaliaikaisia päivityksiä. GitHub Pagesin julkaisu ja oikea puhelinkoe tehdään erikseen.
